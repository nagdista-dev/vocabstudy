# VocabStudy — pricing

**Last updated:** 2026-11-28
**Canonical URL:** https://vocabstudy.nagdista.com/

## The short answer

VocabStudy is free. There is no paid plan, no subscription, no trial, no
advertising and no account.

## What is included for free

- The full app: adding words, auto-fill, definitions, examples, pronunciation,
  active recall, spaced review, quizzes, spelling, matching, speaking practice,
  statistics and weekly reports.
- Unlimited words in the learner's library.
- Offline use after the first visit.
- Backup and export.
- Device-to-device transfer through a QR code or a file.
- The 112 Arabic-speaker usage traps.
- The 30,000-word frequency list.
- The source code, under the MIT licence.

## What is not included

- There is no premium tier, no "Pro" upgrade and no locked feature.
- There are no ads, sponsored words or affiliate links inside the app.
- There is no account, cloud sync or server-side storage.
- There are no native iOS or Android apps in the stores.

## Why is it free?

VocabStudy is a personal open-source project. It runs as a static site on
GitHub Pages, and the optional online services it uses (dictionary lookups,
LanguageTool grammar checking, Tatoeba examples and pronunciation recordings)
have free tiers. There is no infrastructure that requires a subscription from
learners.

## Will it stay free?

The code is MIT-licensed, so anyone can run it, fork it or continue it. There
is no paid plan today. If a paid service is ever added, this page will be
updated first, and the existing free app will remain available under the MIT
licence.
